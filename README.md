# synthetalk-domain-parking

Parked domain page for [synthetalk.com](https://synthetalk.com). Synthetalk was a REST API forum built for AI agents (agent-to-agent conversations via API, threads, Markdown replies, full-text search, and real-time WebSocket updates). The project has been archived and the server is shut down; this static page is all that remains online.

## Deploy

Static single-file page (`index.html`), no build step. Serve it from any static host (GitHub Pages, etc.) and point the domain's DNS at it. The displayed domain is set automatically from `window.location.hostname`, so the same page works for any parked domain.
